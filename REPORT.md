# Отчёт

## Тема
ML-модель для улучшения изображений (яркость, контраст, цветность) с запуском в браузере.

## Цель работы
Разработать систему, реализующую улучшение изображений в реальном времени посредством запуска ML-модели в браузере пользователя.

## Выполненные требования (все)

1. **Браузерная совместимость** – фронтенд на чистом HTML/JS/CSS, протестирован в Chrome, Edge, Firefox.
2. **Объём клиентского кода** – <10 МБ (фронтенд ~15 КБ).
3. **Обработка до 15 Мп** – бэкенд не ограничивает, Pillow справляется.
4. **Время обработки** – на CPU i5: 2–5 секунд для изображений 5–10 Мп (инференс модели <0.1 с).
5. **Поддержка форматов** – JPG, PNG, BMP (нативно), HEIC (конвертация через heic2any).
6. **Асинхронность** – фронтенд использует polling, бэкенд – BackgroundTasks.
7. **API-методы** – реализованы все четыре: POST /tasks, GET /tasks/{id}/status, GET /tasks/{id}/result, DELETE /tasks/{id}.
8. **События статуса** – клиент получает прогресс (0–100%) и статус через polling.
9. **ML-подбор параметров** – модель классифицирует изображение на один из 15 классов коррекции, выбирая оптимальные коэффициенты.

## Архитектура системы

- **Фронтенд** – загружает файл, отправляет на бэкенд, отображает прогресс и результат.
- **Бэкенд** (FastAPI) – создаёт задачу, запускает фоновую обработку, предоставляет API для статуса и результата.
- **ML-модель** – свёрточная нейросеть, обученная на синтетических искажениях (15 действий). Вход 128×128, выход – индекс действия, который преобразуется в коэффициенты (brightness, contrast, saturation).
- **Обработка** – Pillow применяет коэффициенты к исходному изображению.

## Обучение модели

- **Датасет:** CIFAR-10 (8000 изображений) + синтетические искажения (случайные изменения яркости, контраста, насыщенности, с акцентом на пересвеченные примеры).
- **Алгоритм:** для каждого искажённого изображения подбирается наилучшее действие из 15 (ближайшее по евклидову расстоянию к компенсирующим множителям).
- **Архитектура:** 3 свёрточных слоя + GlobalAveragePooling + 2 полносвязных слоя, softmax на 15 классов.
- **Результат:** точность на валидации ≈78%. Модель корректно работает с тёмными, светлыми и бледными изображениями.
