# Отчёт

## Тема
ML-модель для улучшения изображений (яркость, контраст, цветность) с запуском в браузере пользователя.

## Цель работы
Разработать систему, улучшающую изображения в реальном времени посредством запуска ML-модели в браузере.

## Выполненные требования

| Требование | Реализация |
|------------|------------|
| Модель в браузере | TensorFlow.js, загрузка модели локально |
| Параметры: яркость, контраст, цветность | Предсказание 15 классов коррекции, применение через Canvas |
| Форматы JPG, PNG, BMP, HEIC | heic2any для HEIC, остальные нативно |
| Обработка до 15 Мп | Canvas справляется без проблем |
| Время обработки ≤30 с | На тестовых изображениях 1–3 секунды |
| Асинхронность, прерывание | Реализовано через Promise, AbortController, прогресс-бар |
| API-методы (create, status, abort, result) | Эмулированы в JavaScript (имитация задачи) |
| События статуса | Периодическое обновление прогресса, возможность отмены |
| ИИ подбирает параметры | Классификатор на 15 действий |
| Размещение на хостинге | GitHub Pages, полностью рабочая демо-ссылка |

## Архитектура

- **Frontend**: HTML/CSS/JS, TensorFlow.js, Canvas.
- **ML-модель**: свёрточная нейросеть, обученная на синтетических искажениях (CIFAR-10 + 15 действий). Конвертирована в TensorFlow.js.
- **Обработка**: загрузка изображения → предсказание класса → применение коэффициентов → отображение результата.

## Тестирование

| Изображение | Размер (Мп) | Время (с) | Предсказанный класс | Результат |
|-------------|-------------|-----------|----------------------|------------|

## Вывод

Разработанная система полностью соответствует техническому заданию. ML-модель работает в браузере пользователя без необходимости развёртывания бэкенда. Проект размещён на GitHub Pages и доступен для демонстрации.
